# Linear via MCP

Ao receber `PIE-123`, consulte primeiro o MCP do Linear. Ordem preferencial: issue; projeto/épico e pai quando necessários; relações/dependências; comentários relevantes; issues relacionadas somente se o contexto exigir. Prefira ferramentas semânticas do MCP e não faça scraping quando ele estiver disponível.

Se o MCP não estiver disponível, informe: “Não foi possível consultar a tarefa `PIE-123` no Linear porque a ferramenta MCP do Linear não está disponível. Forneça o conteúdo da tarefa ou configure o Linear MCP antes de continuar.” Adapte o ID ao caso real.

Linear é a fonte dos requisitos atuais; código, testes e configuração são a fonte da implementação; ADRs/documentação explicam decisões. Explicite conflitos. Reutilize configuração externa existente e nunca versione credenciais.
