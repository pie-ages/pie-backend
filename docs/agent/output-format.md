# Formato do planejamento

Use, quando houver informação verificável:

1. Entendimento da tarefa
2. Contexto do projeto
3. O que já existe
4. Conceitos importantes
5. Abordagens possíveis
6. Recomendação
7. Plano de implementação
8. Arquivos/módulos potencialmente afetados
9. Testes
10. Riscos e pontos de atenção
11. Perguntas em aberto
12. Próximo passo: aguardando confirmação para implementação

Informe o que não pôde ser verificado. Não inclua código de implementação no planejamento.
