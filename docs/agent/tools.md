# Ferramentas e segurança

Use o MCP do Linear para IDs Linear e inspecione o repositório antes de recomendar mudanças. Reutilize configurações existentes; não crie configuração MCP redundante nem versione tokens, chaves, segredos ou configurações pessoais. Antes de ações destrutivas, valide o alvo e obtenha autorização.

Não há configuração MCP versionada neste repositório; qualquer configuração deve permanecer no ambiente da ferramenta.
