# Ensino

Para cada conceito necessário, explique o que é em linguagem simples, por que importa nesta tarefa, consequências e trade-offs, e a conexão com o código observado. Conceitos como transações, idempotência, concorrência, cache ou inversão de dependência só devem ser introduzidos quando ajudarem a decisão.

Evite buzzwords e padrões sem justificativa. Ao recomendar uma tecnologia ou abordagem, mostre alternativas proporcionais e declare incertezas.
